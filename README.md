# Rocketblog — página inicial

Exercício de interface de blog com destaque editorial, navegação e cartões de publicações. O conteúdo é demonstrativo.

## Tecnologias

- HTML
- CSS
- JavaScript
- jQuery

## Funcionalidades e utilização

Explore a página inicial. Os artigos são conteúdo estático do exercício; não há CMS ou backend.

## Como executar

```bash
git clone https://github.com/EuGeanCarlos/Desafio-roceket-blog.git
cd Desafio-roceket-blog
python -m http.server 8000 --directory "."
```

Requer Python 3 para o servidor local. Abra http://localhost:8000.
